# 聊天文件管理

SillyTavern 聊天文件管理扩展。

## 功能

- 浏览、搜索、排序和分页查看聊天记录
- 在聊天管理和欢迎页按角色或分卷组整理聊天
- 查看、下载和恢复原生聊天备份
- 识别中文名称被转换为下划线的备份文件
- 按楼层范围或固定楼层数创建聊天分卷
- 继续为已有分卷组创建增量分卷
- 单条或批量删除聊天记录
- 增强原生数据清理面板的备份查看和批量操作

## 安装

需要 SillyTavern 1.17.0 或更高版本。

在扩展管理中选择“安装扩展”，输入：

```text
https://github.com/UnrealerNID/sillytavern-chat-manager
```

安装完成后刷新页面。

## 使用

打开“聊天文件”菜单，点击“聊天管理”。

原生聊天文件列表中也会提供查找备份和创建分卷的快捷入口。

## 说明

- 创建分卷会保留原聊天
- 删除聊天前需要确认
- 创建分卷会触发 SillyTavern 原有的备份轮换规则
- 首次读取超大聊天时仍可能占用较多内存
