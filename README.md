# 聊天文件管理

面向 SillyTavern 的纯前端聊天文件管理扩展，用于浏览全部聊天、识别原生备份，以及将过大的聊天记录安全分割为多个新记录。

插件不修改 SillyTavern 源码，也不会覆盖或删除原聊天。

## 功能

### 全部聊天

- 随时查看当前账号下的全部有效聊天记录
- 支持按角色、群聊和聊天内容筛选
- 可分别切换按角色或群组、按分卷组折叠显示
- 分卷组存在原始聊天时一并显示，并用“源”标记；原始聊天不存在时不影响分组
- 即使当前没有选择角色或群聊，也能选择并打开目标聊天

### 备份识别

- 查看指定聊天对应的 SillyTavern 原生备份
- 兼容中文角色名在备份文件名中被转换为下划线的情况
- 结合原生命名规则与聊天内容校验，避免仅凭文件名误判
- 先显示候选备份列表，再逐个更新文件检查结果和进度
- 分页查看备份内容，减少一次性渲染大量消息造成的卡顿

### 聊天分割

- 按消息楼层起止范围生成新聊天记录
- 按指定楼层数自动生成多个分卷
- 分割前预览范围、消息数量和输出名称
- 确认后才创建新记录，原聊天始终保留
- 写入后回读校验，名称冲突时自动追加短数字后缀
- 支持从最后一卷新增的消息继续增量分卷，并沿用或改用组内已保存的配置
- 支持角色聊天与群聊

### 运行保护

- 聊天正在生成时仍可只读浏览
- 生成期间禁止切换聊天和执行分割，避免与酒馆写入流程冲突
- 未完成的分割任务会保留恢复记录，不自动删除已创建的结果

## 安装

要求 SillyTavern 1.18.0 或更高版本。

在 SillyTavern 的“扩展程序”中选择“安装扩展”，填写：

```text
https://github.com/UnrealerNID/sillytavern-chat-manager
```

安装完成后刷新页面。插件设置会显示在扩展程序面板中，功能入口位于原生“聊天文件”菜单项之后。

## 使用

打开 SillyTavern 的聊天文件菜单，点击“聊天管理”进入全部聊天面板。选择一条聊天后，可以打开聊天、识别备份或进入分割预览。

原生聊天文件列表中的每条记录也会显示备份和分割操作按钮。关闭“启用扩展”会通过 SillyTavern 原生机制禁用插件并刷新页面；需要重新启用时，请前往酒馆的扩展管理。

## 更新

插件设置会自动检查远程更新。发现新版本时，版本号旁会显示“更新”按钮；点击后由 SillyTavern 完成更新并自动刷新页面。也可以在酒馆的扩展管理中手动检查更新。

## 使用限制

- 分割使用酒馆原生保存接口，因此会触发酒馆已有的聊天备份与轮换规则
- 备份文件可以分页读取；普通聊天接口仍会返回完整消息数组，首次读取超大聊天时仍可能占用较多内存
- 插件只创建新的分割记录，不负责压缩、覆盖或删除原聊天
