# 聊天文件管理

适用于 SillyTavern 的聊天文件管理扩展，提供聊天浏览、备份识别、聊天分卷和批量删除功能。

扩展不会修改 SillyTavern 源码，也不会在创建分卷或恢复备份时覆盖原聊天。

## 主要功能

- 浏览、搜索、排序和分页查看聊天记录
- 按角色或分卷组折叠显示聊天
- 识别中文角色名被替换为下划线的原生备份
- 分页查看和下载备份，或将备份恢复为新聊天
- 按消息楼层范围或固定楼层数创建分卷
- 沿用已有分卷配置继续创建增量分卷
- 单条或批量删除聊天记录
- 增强酒馆原生数据清理面板中的备份查看与批量操作

## 安装

要求 SillyTavern 1.18.0 或更高版本。

在 SillyTavern 的扩展管理中选择“安装扩展”，输入以下地址：

```text
https://github.com/UnrealerNID/sillytavern-chat-manager
```

安装完成后刷新页面。

## 使用

打开 SillyTavern 的“聊天文件”菜单，点击“聊天管理”。

聊天列表中的操作按钮可用于进入聊天、查看内容、重命名、查找备份、创建分卷和删除聊天。工具栏可切换聊天范围、分组方式和批量删除模式。

原生聊天文件列表中也会显示查找备份和创建分卷入口。

## 注意事项

- 创建分卷只会生成新聊天，原聊天会保留
- 删除聊天前必须经过确认
- 聊天生成或分卷写入期间，部分文件操作会暂时禁用
- 创建分卷会触发 SillyTavern 原有的聊天备份与轮换规则
- 首次读取超大聊天时，仍可能产生较高的内存占用

## 更新

扩展会通过 SillyTavern 检查更新。发现新版本后，可在扩展设置或扩展管理中执行更新。
