# 聊天文件管理

## 能做什么

- 浏览、搜索、排序和分页查看全部聊天
- 在聊天管理和欢迎页按角色或分卷组显示，并保持两边设置同步
- 查看、下载和恢复 SillyTavern 原生聊天备份
- 识别中文名称被替换为下划线的备份文件
- 按指定楼层范围或固定楼层数创建分卷
- 从已有分卷组继续创建增量分卷
- 单条或批量删除聊天记录
- 在原生数据清理面板中补充备份搜索、排序、查看和批量操作

## 安装

需要 SillyTavern 1.17.0 或更高版本，当前主要在 1.18.0 上测试。

打开 SillyTavern 的扩展管理，选择“安装扩展”，填入：

```text
https://github.com/UnrealerNID/sillytavern-chat-manager
```

安装完成后刷新页面，然后从“聊天文件”菜单进入“聊天管理”。原生聊天文件列表中也会出现查找备份和创建分卷的快捷操作。

## 使用前知道这些

- 创建分卷会生成新的聊天文件，原聊天仍会保留
- 删除聊天前会再次确认
- 创建分卷时，SillyTavern 仍会执行自身的备份轮换规则
- 首次读取特别大的聊天文件时，仍可能出现短暂的内存占用升高
